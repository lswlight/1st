# 자동가계부 (안드로이드)

월급은 직접 입력하고, 카드 결제는 **문자 · 카카오톡 알림톡 · 카드사 앱 알림**이 오는 순간 자동으로 지출에 기록하는 간단한 가계부입니다.
복잡한 기능(예산, 카테고리, 통계, 클라우드 동기화)은 일부러 뺐습니다.

## 화면

- **월 이동** ◀ 2026년 10월 ▶
- **요약**: 수입 / 지출 / 남은 돈
- **+ 수입**: 월급 등 수입 입력 (내용 기본값 "월급")
- **+ 지출**: 현금 등 직접 입력
- **문자 붙여넣기**: 자동 기록이 안 된 문자를 붙여 넣으면 금액·사용처를 읽어서 채워 줌 (내 카드 문자가 잘 읽히는지 시험할 때도 사용)
- **📅 달력 · 📊 그래프로 보기**: 월간 내역을 달력(날짜별 지출 금액, 많이 쓴 날일수록 진한 색, 수입 있는 날 파란 점, 날짜를 누르면 그날 내역)과
  그래프(일별 지출 막대 + 하루 평균선, 최근 6개월 수입·지출, 카드별 지출, 많이 쓴 곳 TOP 5)로 봅니다
- **💳 카드별 지출**: 카드(결제 수단)별 실제 지출 = 결제 - 취소 - 혜택(할인·캐시백). 카드를 누르면 그 달 내역이 펼쳐집니다
- **환율·수수료**: 해외 결제 환산에 쓰는 환율 확인, 지금 받기, 해외 이용 수수료율(%) 설정
- **최근 감지 알림**: 앱이 받은 문자·카카오톡·카드 앱 알림 원문과 처리 결과(기록됨 / 결제 문구 아님 / 중복이라 건너뜀). 자동 기록이 안 될 때 원인 확인용
- **내역 목록**: 날짜별로 묶어서 표시. 누르면 수정·삭제. 자동 기록된 내역은 "자동" 표시와 원본 알림 문구가 남음

## 자동 기록 동작 방식

안드로이드의 **알림 접근(NotificationListenerService)** 으로 폰에 뜨는 알림을 읽습니다.
문자를 직접 읽는 SMS 권한은 쓰지 않습니다. 문자 앱이 띄우는 알림을 읽으므로 문자도 함께 잡힙니다.

| 알림 출처 | 기록 조건 |
|---|---|
| 문자 앱 (삼성 메시지, Google 메시지) | 카드사 문구(`카드`, `체크`, `삼성1234승인` 등) + 금액 + 승인/결제/취소 |
| 카카오톡 | 카드사 알림톡일 때만 (친구 대화는 카드 문구가 없으면 무시) |
| 카드사 앱 (패키지명에 `card` 포함), 토스, 카카오페이, 카카오뱅크, NH pay, 페이북 | 금액 + 결제 문구 |
| 은행 앱 (앱 이름에 은행·뱅크·뱅킹·금고·신협·우체국 포함, 예: MG새마을금고) | 체크카드 **승인** 알림과 자동이체 출금만 (계좌 출금·이체·입금은 무시) |

- **해외 결제** (`JPY 2,280`, `USD 12.50` 등)는 그날 환율로 원화 환산하고 설정한 해외 이용 수수료율을 더해 기록합니다.
  사용처 옆에 `(JPY 2,280 × 9.30원 + 수수료 1.4%, 추정)` 처럼 원래 금액과 계산 근거를 남깁니다.
  - 환율은 해외 결제가 있는 날 하루 한 번 무료 공개 서비스(open.er-api.com, 안 되면 fawazahmed0 currency-api)에서 받아 저장합니다.
  - 인터넷이 안 되면 마지막으로 받은 환율, 그것도 없으면 앱에 넣어 둔 고정 추정치를 씁니다.
  - 수수료율과 받아 둔 환율은 **[환율·수수료]** 화면에서 확인·변경합니다 (기본 2%).
  문구에 원화 금액이 함께 있으면 그 금액을 씁니다. 실제 청구 금액이 나오면 내역을 눌러 고치면 됩니다.
- 앱 이름에 "카드"가 들어간 앱(예: 하나Pay 의 "하나카드")도 카드사 앱으로 인식합니다.
- **체크카드 결제와 계좌 이체 구분**: 은행 앱은 체크카드 결제 때 `[출금]` 알림과 함께 `MG체크카드(9*1*) 18,500원 승인 …` 같은 **승인** 알림을 따로 보냅니다.
  그래서 승인 알림으로만 지출을 기록하고, 승인 없는 계좌 `[출금]` 알림(이체·송금·ATM)은 기록하지 않습니다. 자동이체(통신비·관리비 등) 출금만 예외로 기록합니다.
- 은행 **입금**(월급 등)은 기록하지 않습니다.
- **내 계좌끼리 옮긴 돈**: 혹시 출금이 기록된 경우에도, 같은 금액의 입금 알림이 앞뒤 5분 안에 오면 이체로 보고 그 출금 기록을 지웁니다.
- 문구만으로 체크카드 결제와 구분되지 않는 이체(상대 이름만 오는 경우)는 **[기록 제외]** 목록에 상대 이름을 넣으면 걸러집니다.
  자동 기록된 내역을 눌러 **이 상대는 앞으로 기록 안 함** 을 누르면 목록에 바로 추가되고 그 내역도 지워집니다.
- **적립 안내**(예: 토스 "4,360원 적립됐어요", 결제 문자 속 "포인트 적립 예정")는 지출로 기록하지 않습니다.
- **할인·캐시백 혜택** (금액 앞에 `-` 가 붙어 온 알림, 예: `-1,500원 커피전문점 할인`)은 **수입**으로 기록하고 내용 앞에 "카드 혜택:" 을 붙입니다.
  잘못 분류된 내역은 눌러서 **수입으로 바꾸기 / 지출로 바꾸기** 로 고칩니다.
- **승인 취소** 문자는 음수 금액(환불)으로 기록되어 지출 합계에서 빠집니다.
- **누적 · 잔액 · 한도** 금액은 무시하고 실제 결제 금액만 읽습니다.
- **승인거절, 결제예정금액, 청구서, (광고), 인증번호** 문자는 기록하지 않습니다.
- 같은 결제가 문자와 카드 앱으로 **두 번 오면** (같은 금액, 3분 이내) 한 번만 기록합니다.

해석 규칙은 [`CardMessageParser.kt`](app/src/main/java/com/lswlight/moneybook/CardMessageParser.kt), 테스트 예시 문구는 [`CardMessageParserTest.kt`](app/src/test/java/com/lswlight/moneybook/CardMessageParserTest.kt) 에 있습니다.
내 카드 문자가 잘 안 읽히면 그 문구를 테스트에 추가하고 규칙을 고치면 됩니다.

## 설치 (폰)

1. 이 저장소의 **Releases → `moneybook-latest`** 에서 `moneybook.apk` 를 폰으로 받습니다.
   (GitHub Actions 가 `expense-app/` 이 바뀔 때마다 자동으로 빌드해 올립니다. Actions 탭의 `moneybook-apk` 아티팩트로도 받을 수 있습니다.)
2. 설치 시 "출처를 알 수 없는 앱" 허용을 묻으면 허용합니다.
3. 앱을 열고 **알림 접근 설정 열기 → 자동가계부 허용**.
4. **Android 13 이상**에서 알림 접근 스위치가 회색으로 막혀 있으면 (스토어 밖에서 설치한 앱 제한):
   설정 → 애플리케이션 → 자동가계부 → 오른쪽 위 ⋮ → **제한된 설정 허용** → 다시 3번.
5. 화면 요약 아래 **자동 감지: 동작 중 ●** 이 보이면 정상입니다. **연결 안 됨**이 계속되면 (앱 업데이트 직후 가끔 생김)
   알림 접근 설정에서 자동가계부를 껐다가 다시 켜 주세요.
6. 삼성 폰은 설정 → 배터리 → 백그라운드 사용 제한에서 자동가계부를 **절전 예외**로 두면 알림을 놓치지 않습니다.
7. 카카오톡 알림톡을 쓰려면 카카오톡 알림이 켜져 있고, 카카오톡 설정 → 알림 → **메시지 미리보기**가 켜져 있어야 합니다.
   미리보기가 꺼져 있으면 알림에 "새로운 메시지가 있습니다"만 와서 금액을 읽을 수 없습니다. 해당 카드사 채널의 채팅방 알림이 꺼져 있어도 안 됩니다.

> iPhone 은 다른 앱의 알림이나 문자를 읽는 것을 허용하지 않아 이 방식이 불가능합니다. 안드로이드 전용입니다.

## 가족 가계부 (함께 보기)

가족 모두의 내역을 **내 구글 시트 하나**에 모아 각자 폰의 **[👨‍👩‍👧 가족 가계부]** 화면에서 함께 봅니다. 별도 서버·가입은 없습니다.

1. 처음 만드는 사람: [가족 가계부] → [공유 설정] → **[스크립트 복사]**
2. 구글 드라이브에서 새 스프레드시트 → 확장 프로그램 → **Apps Script** → 내용을 지우고 붙여 넣기 → 저장
3. **배포 → 새 배포 → 유형: 웹 앱**, 실행: 나, 액세스 권한: **모든 사용자** → 배포 (처음엔 구글 권한 허용 필요) → **웹 앱 URL 복사**
4. 앱 [공유 설정]의 '시트 주소'에 붙여 넣고 **내 이름**(예: 남편) 적고 저장 → **[지금까지 내역 모두 올리기]**
5. **[공유 코드 복사]** → 카카오톡으로 가족에게 전송
6. 가족 폰: [가족 가계부] → [공유 설정] → '받은 공유 코드'에 붙여 넣기, 내 이름(예: 아내) 적고 저장

- 저장·수정·삭제할 때마다 시트에 바로 올라가고, 가족 화면은 열 때·[새로고침] 누를 때 최신 내역을 받습니다. 인터넷이 안 될 때 못 올린 내역은 앱을 다시 열 때 이어서 올립니다.
- 시트에는 사용처·금액·카드·시각·이름만 올라가고 원본 알림 문구는 올리지 않습니다. 시트 주소와 공유 비밀번호를 아는 사람만 읽고 쓸 수 있습니다.
- 내 내역을 올리지 않고 보기만 하려면 [공유 설정]에서 '내 내역도 가족 가계부에 올리기'를 끄면 됩니다.

## 데이터

- 내역은 폰 안의 SQLite 파일(`moneybook.db`)에만 저장되고 외부로 전송되지 않습니다.
  인터넷은 환율표를 받을 때와, 가족 가계부를 켰을 때 내 구글 시트와 주고받을 때만 씁니다.
- 앱을 지우면 데이터도 지워집니다. 업데이트는 새 APK 를 그대로 덮어 설치하면 데이터가 유지됩니다
  (저장소의 `app/debug.keystore` 로 항상 같은 서명을 하기 때문. 개인용 서명 키라 비밀 값은 아닙니다).

## 직접 빌드

Android Studio 로 `expense-app` 폴더를 열거나, Android SDK 가 있는 PC 에서:

```bash
cd expense-app && ./gradlew testDebugUnitTest assembleDebug
```

결과물: `app/build/outputs/apk/debug/app-debug.apk`

## 구조

```
expense-app/app/src/main/java/com/lswlight/moneybook/
├── MainActivity.kt               # 화면 (월 요약, 내역, 입력 창) — 레이아웃 XML 없이 코드로 구성
├── CardNotificationListener.kt   # 알림 감지 → 파싱 → 중복 확인 → 저장
├── CardMessageParser.kt          # 카드 문자/알림 문구 해석 (안드로이드 의존성 없음)
└── LedgerDb.kt                   # SQLite 저장소
```

외부 라이브러리 없이 안드로이드 기본 API 만 사용합니다 (최소 Android 8.0).
