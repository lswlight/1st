# kr-scanner

차트를 하나하나 넘겨 보는 일을 대신하는 도구다. 규칙에 맞는 차트 목록일 뿐
매수 목록이 아니다. 데이트레이딩은 대부분의 사람에게 손실을 안긴다.

`<이 폴더>` 는 이 SKILL.md 가 있는 폴더다. 결과는 현재 폴더의 `krt/` 에 쓴다.

```bash
python3 "<이 폴더>/scan.py" daily                       # 국내, 장 전 (전날 종가 기준)
python3 "<이 폴더>/scan.py" daily --market crypto       # 코인 (09:00 KST 일봉 기준)
python3 "<이 폴더>/scan.py" orb                         # 국내, 09:20 이후
python3 "<이 폴더>/scan.py" orb --market crypto         # 코인, 09:20 KST 이후
python3 "<이 폴더>/scan.py" daily --symbols 005930,120110,298050
python3 "<이 폴더>/scan.py" orb --at 09:45              # 09:45까지만 본다
python3 "<이 폴더>/scan.py" universe --market krx --check   # 종목 목록 다시 검증
```

옵션: `--min-value` (일봉 최소 거래대금, 국내 기본 10억 원), `--min-price`,
`--show N`, `--json`, `--no-write`, `--now "2026-10-29 10:15"` (한국 시간),
`--offline 폴더` (저장된 Yahoo·업비트 파일).

## 데이터와 한계

- 국내 주식: Yahoo 무료 차트 (`005930.KS` 코스피, `247540.KQ` 코스닥). 지연 시세이고 비공식이다.
- 코인 기본: **바이낸스 현물 USDT** (`BTCUSDT`). `api.binance.com` 은 서버 위치를 막아(451) 시세 전용 공개 주소
  `data-api.binance.vision` 을 쓴다 (네트워크 허용 목록에 있어야 함). 가격은 USDT, 거래대금은 $로 표시한다.
- 코인 보조: **업비트 원화** (`BTC-KRW`, `api.upbit.com`). 심볼에 `-KRW` 를 붙이면 업비트로 본다. 거래가 없어 빠진 5분봉은 직전 종가로 채운다.
  업비트는 요청당 약 1초라 느리다. `"crypto_source": "upbit"` 이면 `btc` 를 `BTC-KRW` 로 해석하고, `"yahoo"` 면 Yahoo 원화 환산 시세를 쓴다.
- 종목명만 쓰면(`btc`) 기본 데이터원(`crypto_source`, 기본 binance)을 따른다.
- **Yahoo는 접미사가 틀린 국내 종목에도 엉뚱한 값을 준다** (`005930.KQ` 도 값이 나옴).
  도구는 거래소 코드(KSC=코스피, KOE=코스닥)가 맞지 않으면 버린다.
- 국내 5분봉은 09:00~14:55 봉(72개)만 있다. 15:00 이후 체결과 종가 단일가는 없다.
- 코인의 하루는 업비트 일봉과 같이 09:00 KST에 시작한다. "개장 15분"은 09:00~09:15다.
- 종목 목록은 `universe-krx.txt`, `universe-crypto.txt` (후보는 `candidates-*.txt`).
  국내 종목을 넣고 빼려면 후보 파일을 고친 뒤 `universe --check` 를 돌린다.
  코인 목록은 `universe --market crypto --check [--top 30]` 이 바이낸스 USDT 거래대금 상위로 다시 만든다
  (스테이블코인, 레버리지 토큰, 토큰화 주식(GOOGLB 등) 제외). `--exchange upbit` 이면 업비트 원화 목록(`universe-upbit.txt`, 투자유의 제외).
- KRX·네이버 API는 이 환경의 네트워크에서 막혀 있어 쓰지 않는다.

## 일봉 셋업 (볼린저 20일, 2σ)

| 셋업 | 규칙 |
| --- | --- |
| 볼린저 스퀴즈 후 상단 돌파 | 전날 밴드폭이 최근 120일 중 하위 20% 이내, 오늘 종가가 상단 위 |
| 볼린저 스퀴즈 진행 중 | 오늘 밴드폭이 최근 120일 중 하위 10% 이내 (돌파 대기) |
| 볼린저 하단 이탈 후 복귀 | 전날 종가가 하단 아래, 오늘 종가가 하단 위 |
| 20일 종가 신고가 | 오늘 종가가 직전 20일 종가보다 모두 높음 |
| 20일선 회복 | 전날 종가가 20일선 아래, 오늘 종가가 위 |
| 과매도 | RSI 14 (Wilder) 30 미만 |

각 결과에 %B, 밴드폭, 밴드폭 순위(낮을수록 수축), RSI 를 붙인다. 거래대금 순.
국내는 15:30 전이면 오늘 일봉을 빼고, 코인은 진행 중인 오늘(09:00 이후) 일봉을 뺀다.

## 개장 범위 돌파 (장중)

개장 15분(09:00, 09:05, 09:10 봉)의 고가·저가가 범위다. 그 뒤 처음으로 5분봉
**종가**가 범위 고가 위에서 마감한 봉이 신호다. 국내는 14:30(`krx_last_entry`) 이후 신호는
만료로 본다. 5분봉이 하나라도 빠진 차트(거래정지·거래 부족)는 쓰지 않는다.
145개 전체가 약 1분 걸린다.

## 순서

1. 장 전: `daily` (국내), 필요하면 `daily --market crypto`. 받은 수, 통과 수, 스캔 수, 셋업별 개수와 상위 종목을 말한다.
2. 장중 09:20 이후: `orb`. 몇 개가 언제 돌파했는지 말하고, 늦게 돌파한 것이 지금 가격에 가깝다고 말한다.
3. 사용자가 고르면 `/kr-news 종목` (공시·뉴스) → `/kr-plan` (진입·손절·수량)으로 넘긴다. 대신 골라 주지 않는다.

## 규칙

- 무엇을 몇 개 스캔했고 데이터가 언제 것인지 말한다. 일부만 받았으면 일부라고 말한다.
- "규칙에 맞았다"고만 말한다. "매수", "유망", "좋은 거래"라고 하지 않는다. 수익률을 말하지 않는다.
- 신호는 가격이 움직이면 낡는다. 행동하기 전에 다시 돌린다.
- 주문을 내거나 종목을 추천하지 않는다. 투자 조언이 아니다.
