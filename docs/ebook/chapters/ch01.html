바이브 코딩이란

바이브 코딩(vibe coding)은 코드를 직접 쓰지 않고, AI에게 "이런 걸 만들고 싶어"라고 말로 설명해서 프로그램을 만드는 방식입니다. 사람은 원하는 것을 말하고, 결과를 써 보고, 마음에 들지 않는 부분을 다시 말합니다. 코드를 쓰고 고치고 실행해 보는 일은 AI가 합니다.

이 책의 저자는 개발자가 아닙니다. 회사에서 타이어 코오드 접착액을 연구하는 직장인입니다. 퇴근 후와 주말에 휴대폰과 PC로 AI와 대화하며 2주 남짓 만에 안드로이드 앱을 만들었고, 회사 계정으로 구글 플레이스토어 심사까지 제출했습니다. 코드는 한 줄도 직접 쓰지 않았습니다. 이 책은 그 과정을 처음부터 끝까지, 실제로 AI에게 한 말과 실제로 막혔던 화면 그대로 정리한 기록입니다.

이 책의 사례: 자동가계부

만든 앱은 '자동가계부'입니다. 기능은 단순합니다. 월급은 직접 입력하고, 카드를 쓰면 휴대폰에 오는 문자·카카오톡 알림톡·카드사 앱 알림을 앱이 읽어서 지출을 자동으로 적습니다. 가계부를 쓰다가 그만두는 가장 큰 이유가 "매번 적기 귀찮아서"라는 데서 출발했습니다.

처음에는 내 폰에만 깔아 쓰는 작은 앱이었습니다. 쓰다 보니 아내도 같이 보고 싶어 했고(아내는 아이폰을 씁니다), 그러다 보니 서버가 생기고, 다른 사람도 쓰게 하고 싶어져 회사 계정과 도메인을 만들고, 결국 플레이스토어에 올리게 되었습니다. 작게 시작해 필요할 때마다 키운 과정이라, 같은 순서로 따라오면 부담이 적습니다.

준비물

1. Claude와 Claude Code

이 책에서 쓴 AI는 Anthropic의 Claude이고, 그중 코드를 다루는 Claude Code를 썼습니다. Claude Code는 컴퓨터에 설치해서 쓸 수도 있지만, 저자는 클라우드 세션(웹 claude.ai/code, 휴대폰·PC의 Claude 앱)으로만 썼습니다. 클라우드 세션은 AI가 인터넷 저편의 작업용 컴퓨터에서 코드를 만들고 실행하므로, 내 PC에 개발 도구를 하나도 깔 필요가 없습니다. 출퇴근길에 휴대폰으로 "이거 고쳐 줘"라고 말해 두고, 저녁에 결과를 확인하는 식으로 진행할 수 있었습니다.

Claude Code를 쓰려면 유료 요금제가 필요합니다. 요금제는 바뀔 수 있으니 가입할 때 Claude 홈페이지에서 확인하세요.

2. GitHub 계정과 저장소

GitHub(깃허브, 코드를 보관하는 인터넷 창고) 계정을 만들고, 앱 코드를 담을 저장소(repository, 프로젝트 폴더 하나)를 하나 만듭니다. AI가 만든 코드는 모두 여기에 저장되고, 고칠 때마다 기록이 남아 언제든 이전 상태로 되돌릴 수 있습니다. 또 GitHub에는 GitHub Actions라는 자동 작업 기능이 있어, 코드가 바뀔 때마다 앱 설치 파일을 클라우드에서 자동으로 만들어 줍니다(2장).

  1. github.com에서 가입이메일 인증까지 마칩니다. 2단계 인증을 켜 두는 것이 좋습니다.
  2. 새 저장소 만들기오른쪽 위 + → New repository. 이름은 영어로 짧게(예: 1st, moneybook). 공개(Public)·비공개(Private) 모두 됩니다. 저자는 공개 저장소를 썼고, 그 덕분에 설치 파일 다운로드 링크를 로그인 없이 가족에게 줄 수 있었습니다.
  3. Claude에 GitHub 연결claude.ai/code에서 GitHub 계정을 연결하고 방금 만든 저장소를 고릅니다. 이제 세션을 열면 AI가 그 저장소에서 작업합니다.
공개 저장소에 올리면 안 되는 것 공개 저장소는 누구나 볼 수 있습니다. 비밀번호, API 토큰, 서명 키 파일, 집 주소·전화번호를 코드나 문서에 넣지 마세요. 이런 값은 9장에서 설명할 GitHub Secrets(비밀값 보관함)에 사람이 직접 넣습니다. AI에게도 "비밀값은 커밋하지 마"라고 처음에 한 번 말해 두면 좋습니다.

3. 안드로이드 휴대폰

만든 앱을 설치해서 실제로 써 볼 폰이 필요합니다. 저자는 갤럭시를 썼습니다. 이 앱처럼 다른 앱의 알림을 읽는 기능은 아이폰에서는 허용되지 않아 안드로이드 전용입니다. 여러분의 앱이 그런 기능을 쓰지 않는다면 이 부분은 신경 쓰지 않아도 됩니다.

4. 플레이스토어까지 갈 때만 필요한 것

  • Google Play 개발자 계정: 등록비 25달러(1회). 8장.
  • 조직(회사) 계정으로 갈 경우: 사업자, D-U-N-S 번호(무료), 회사용 구글 계정, 회사 도메인과 웹사이트. 7장.
  • 서버가 필요한 경우: Cloudflare 계정(무료 한도로 충분). 6장.

AI와 일하는 법: 처음에 알아 두면 좋은 7가지

2주 동안 수백 번 대화하며 익힌 습관입니다. 다음 장부터 나오는 대화 예시에서 이 습관이 어떻게 쓰였는지 볼 수 있습니다.

  1. 목적을 먼저, 방법은 나중에"NotificationListener로…" 같은 기술 용어는 몰라도 됩니다. "카드 알림이 오면 자동으로 적히면 좋겠다"처럼 무엇이 되면 좋은지를 말하세요. 방법은 AI가 제안합니다.
  2. 한 번에 하나씩고칠 것이 다섯 개라도 한 번에 한두 개씩 말하는 편이 결과가 정확합니다. 큰 요청은 "먼저 계획을 보여 줘"라고 하면 AI가 단계를 나눠 줍니다.
  3. 말보다 캡처"안 돼"보다 안 되는 화면 캡처 한 장이 훨씬 빠릅니다. 알림 문구, 오류 메시지, 이상한 화면을 그대로 찍어 보내세요(4장).
  4. 실제 데이터를 그대로"카드 문자가 안 읽혀"보다 실제 문자 문구를 붙여 넣는 것이 좋습니다. 단, 카드번호 뒷자리·이름 같은 개인정보는 가리거나 지우고 보내세요.
  5. 모르는 건 물어보기"환율을 연동할 수 있는 방법이 있어?"처럼 가능 여부부터 물어보면, AI가 방법과 비용·한계를 설명해 줍니다. 결정은 내가 합니다.
  6. 아니라고 말하기결과가 기대와 다르면 솔직하게 말하세요. "내가 보낸 사진 그대로 썼네. 사진 위에 안내를 그려 줄 줄 알았어" 같은 피드백 한 줄로 결과물이 확 달라졌습니다(3장).
  7. 비밀값은 채팅에 붙여 넣지 않기비밀번호, API 토큰은 채팅창이 아니라 GitHub Secrets나 전용 보안 입력창으로 넣습니다. AI가 답을 영어로 하면 "한국어로 답해 줘"라고 하면 됩니다.
