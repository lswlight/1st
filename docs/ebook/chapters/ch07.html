앱을 플레이스토어에 올리려면 Google Play Console에 개발자로 등록해야 합니다. 이때 개인 계정과 조직(회사) 계정 중 하나를 고릅니다. 저자는 조직 계정을 골랐고, 그 준비로 이 장의 일들을 했습니다.

  4. 회사 Cloudflare 계정으로 서버 옮기기 + API 토큰으로 AI에게 맡기기

따라 하기① D-U-N-S 번호

D-U-N-S 번호는 Dun & Bradstreet(D&B)라는 회사가 전 세계 기업에 붙이는 9자리 고유 번호입니다. 구글·애플이 "이 회사가 진짜 있는 회사인가"를 확인할 때 씁니다. 무료로 받을 수 있고, 발급까지 며칠에서 몇 주 걸립니다. 가장 오래 걸리는 단계이니 가장 먼저 신청하세요.

  1. 내 회사에 이미 번호가 있는지 조회D&B 사이트나 구글 Play Console 가입 과정의 안내 링크에서 회사 이름·주소로 조회합니다.
  2. 없으면 무료 신청회사 이름(영문), 사업장 주소, 대표자, 연락처, 사업자 정보를 넣습니다. 영문 주소·영문 회사명은 나중에 Play Console에 넣을 값과 똑같이 맞춰 두세요.
  3. 확인 연락에 답하기D&B나 국내 대행 기관에서 확인 메일·전화가 올 수 있습니다. 회사 소개 자료를 요구하면 사업 내용을 정리한 페이지를 보여 줍니다.
  4. 번호를 받으면 보관Play Console 조직 계정 가입 때 입력합니다.
AI 활용 신청 경로와 화면은 자주 바뀝니다. "한국 회사가 D-U-N-S 번호를 무료로 받는 최신 방법 알려 줘"라고 물어보고, 영문 회사명·주소 표기도 AI에게 맞춰 달라고 하면 편합니다. 저자는 사업 내용을 정리한 노션 페이지를 DUNS 신청용으로만 썼고, 상세 주소가 들어 있어 외부에는 공유하지 않았습니다.

따라 하기② 회사용 구글 계정

Play Console은 구글 계정으로 가입합니다. 저자는 개인 계정과 분리하려고 회사용 구글 계정(graft.korea@gmail.com)을 새로 만들었습니다. 회사 앱의 소유자를 회사 계정으로 두면, 나중에 담당자가 바뀌어도 넘기기 쉽고 개인 메일이 스토어에 노출되지 않습니다.

  • 2단계 인증은 Play Console에서 필수입니다. 만들자마자 켜 두세요.
  • 복구용 휴대폰 번호·메일을 꼭 등록하세요. 회사 계정을 잃으면 앱도 관리할 수 없습니다.

따라 하기③ 회사 도메인 사기

조직 계정은 조직 웹사이트를 요구하고, 그 사이트의 소유를 인증해야 합니다(8장). 처음에는 노션 페이지 주소를 넣었지만, 노션 주소는 내 것이라고 증명할 수 없어 인증이 안 됩니다. 그래서 회사 도메인을 샀습니다.

처음 원한 graft.com은 이미 다른 사람이 가지고 있었습니다(판매하지 않음). 짧고 좋은 .com 주소는 대부분 주인이 있습니다. 회사 이름 뒤에 나라·업종을 붙이는 것이 현실적입니다. 저자는 graftkorea.com으로 정했습니다.

.com, .io, .ai는 왜 가격이 다를까?

도메인 끝부분마다 관리하는 기관과 도매가가 다릅니다. .com은 가장 흔하고 싸며 안정적입니다. .ai는 원래 앵귈라라는 나라의 국가 도메인인데, AI 붐으로 수요가 몰려 비쌉니다. 회사 사이트라면 .com이 무난합니다.

왜 Cloudflare에서 샀나

서버가 이미 Cloudflare에 있어서, 같은 곳에서 사면 도메인 연결이 버튼 몇 번으로 끝납니다. Cloudflare는 도매가 그대로 팔아 .com이 연 11.17달러였습니다.

  1. Cloudflare 대시보드 → Domain Registration → Register Domains원하는 이름을 검색해 살 수 있는 주소를 고릅니다.
  2. 등록자 정보(Registrant) 입력회사 이름 GRAFT, D-U-N-S에 넣은 것과 같은 회사 주소, 회사 메일을 넣습니다. 이 정보는 외부 공개 조회(WHOIS)에서 자동으로 가려집니다.
  3. 결제 → "Your domain is ready"보통 몇 분이면 끝납니다.
새 도메인이 폰에서 안 열린다: "서버 IP 주소를 찾을 수 없습니다"

PC에서는 열리는데 폰(LTE)에서만 안 열렸습니다. 도메인을 새로 사거나 바꾸면 그 정보가 전 세계의 DNS(도메인 이름을 서버 주소로 바꿔 주는 전화번호부)에 퍼지는 데 시간이 걸립니다. 통신사 DNS가 예전 정보(아직 없는 도메인)를 기억하고 있던 것입니다.

  • 기다리기: 보통 몇 분~몇 시간, 길면 하루.
  • 비행기 모드 껐다 켜기, 와이파이↔데이터 바꿔 보기.
  • 폰 설정의 개인 DNS를 one.one.one.one이나 dns.google로 바꾸기.

사이트가 고장 난 것이 아니니 서버를 고치려고 하지 마세요.

따라 하기④ 회사 Cloudflare 계정과 API 토큰

6장의 서버는 개인 Cloudflare 계정에 있었습니다. 회사 앱의 서버는 회사 계정에 있어야 하므로 회사용 Cloudflare 계정을 새로 만들고(2단계 인증) 서버를 옮겼습니다. 이번에는 대시보드에서 직접 하지 않고, API 토큰을 만들어 AI에게 맡겼습니다(6장 "니가 해줄 수 없나?").

토큰에는 AI가 해야 할 일에 필요한 권한만 넣습니다.

따라 하기⑥ Search Console로 도메인 소유 인증

Play Console의 웹사이트 인증(8장)은 Google Search Console에서 그 도메인의 소유자로 인증되어 있어야 통과합니다. Cloudflare에서 산 도메인은 자동 연결로 쉽게 끝납니다.

  1. 회사 구글 계정으로 Search Console 접속 → 속성 추가 → '도메인'에 graftkorea.com
  2. DNS 공급업체가 Cloudflare로 인식되면 자동 인증 시작Cloudflare 로그인 창이 뜨고, 구글이 추가할 TXT 기록(인증용 글자)이 보입니다.
  3. [Authorize]한 번만 허락하는 것이고, 구글이 이후에 마음대로 바꿀 수는 없습니다.
Authorize를 눌렀더니 "Unauthorized · Error 401"

오류 화면이 떴지만, 실제로는 TXT 기록이 이미 들어가서 인증에 성공한 상태였습니다. 창이 넘어가는 과정에서만 오류가 난 것입니다. 이런 화면을 보면 당황하지 말고 실제 결과를 확인하세요.

  • Cloudflare → graftkorea.com → DNS → Records에 google-site-verification으로 시작하는 TXT 기록이 있는지 본다.
  • Search Console을 새로고침해 '소유권 확인됨'을 본다.
  • 둘 다 없으면 AI에게 오류 캡처를 보내고 "TXT 기록을 직접 넣는 방법 알려 줘"라고 한다.
TXT 기록을 지우지 마세요 인증을 유지하려면 그 TXT 기록이 계속 있어야 합니다. DNS를 정리할 때 '모르는 기록'이라고 지우면 인증이 풀립니다.
7장 체크리스트
  • 개인 계정과 조직 계정 중 하나를 골랐다(조직: 사업자 필요)
  • D-U-N-S 번호를 신청했다(가장 오래 걸리니 가장 먼저)
  • 회사용 구글 계정을 만들고 2단계 인증을 켰다
  • 회사 도메인을 사고, 등록자 정보를 DUNS와 같게 넣었다
  • 새 도메인이 안 열리면 DNS 반영을 기다렸다
  • 필요한 권한만 넣은 API 토큰을 보안 입력창으로 전달하고, 작업 후 삭제했다
  • 회사 사이트·개인정보처리방침(/privacy)·이용약관(/terms)을 만들고, 연락처가 회사 메일인지 확인했다
  • Search Console에서 도메인 소유권 확인을 마쳤다
