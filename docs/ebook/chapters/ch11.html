A. 전 과정 체크리스트

처음부터 따라 할 때 이 목록을 옆에 두고 하나씩 지워 가세요. 괄호 안은 자세한 설명이 있는 장입니다.

준비 (1장)
  • 만들 앱을 "직접 할 것 / 자동으로 될 것 / 뺄 것"으로 한 문단에 정리했다
  • Claude 유료 요금제, GitHub 계정·저장소, Claude–GitHub 연결
  • 설치해 볼 안드로이드 폰
만들고 설치하기 (2~3장)
  • 첫 요청 + "PC에 아무것도 안 깔고 링크로 설치" + "항상 같은 서명"
  • GitHub Actions 빌드 성공, 고정 다운로드 링크
  • 폰 설치(출처 허용, Play 프로텍트·자동 차단 잠시 끄기), 알림 접근 허용
고치고 키우기 (4~5장)
  • 진단 화면(받은 원문 + 처리 결과)
  • 고친 사례는 테스트에 추가
  • 화면·디자인은 캡처와 시안으로 대화
  • 만들지 않을 기능은 과감히 접기
서버 (6장, 필요할 때)
  • 보내는 정보 최소화, 공유 끄기 = 서버 삭제
  • Cloudflare D1 + Workers + 바인딩 DB
  • API 토큰은 보안 입력창으로, 작업 후 삭제
회사와 계정 (7~8장, 조직 계정일 때)
  • D-U-N-S 신청(가장 먼저), 회사 구글 계정(2단계 인증)
  • 도메인 구입, 회사 사이트·/privacy·/terms, 연락처는 회사 메일
  • Search Console 도메인 인증
  • Play Console 가입(25달러), 개발자 이름, 웹사이트 인증, 판매자 선언, 전화 인증
출시 (9~10장)
  • 대상 API 기준 충족(2026년: API 36), 최신 에뮬레이터 화면 확인
  • 패키지 이름 확정, 업로드 키 → GitHub Secrets 4개, AAB 빌드
  • 무료/유료, 앱 이름, 카테고리
  • 아이콘 512, 그래픽 1024×500, 스크린샷 1080×1920 4장 이상, AI 애셋 라벨
  • 내부 테스트 설치 확인 → 등록정보 → 앱 콘텐츠 → 프로덕션(국가) → 검토 제출

D. AI에게 실제로 한 말 모음

이 책에 나온 저자의 실제 발화를 모았습니다. 기술 용어가 하나도 없다는 데 주목하세요.

한 말상황
"나는 수입 지출 앱을 만들고 싶어. 다른 복잡한 기능은 빼고 … 알림이 날라오면 이를 캐치하고 자동으로 바로 기입을 하는 형태의 어플을 만들고 싶어."첫 요청(2장)
"문자로 오는 것은 정상적으로 잘 되고 카카오톡으로 오는 것은 안 돼."버그 보고(4장)
"하나카드의 해외카드 결제가 방금 이루어졌는데 반영이 되지 않았어"버그 보고(4장)
"환율을 연동할 수 있는 방법이 있어?" / "수수료는 여유있게 2%로 하자"가능 여부 묻고 결정(5장)
"카드 혜택에서 … 할인받은 금액은 -(음수)로 알람이 오니 +수입 처리가 되어야 하는데 지출 처리가 되었어."기대와 실제(4장)
"체크카드의 경우 사용시 입출금 형태로 되는데 일반 계좌 이체랑 구분할 수 있나?"문제 제기(5장)
"승인 알림이 있어. 이걸 기준으로 체크카드 사용을 구분할 수 있지 않을까?"사용자 아이디어(5장)
"내가 보낸 사진 그대로 썼네. 난 보기 좋게 사진에다가 가이드 안내글 적어줄 수 있을 줄 알았어"결과물 피드백(3장)
"첫 사진 보면 … 너무 타이트해 … 글자가 겹쳐 … 되돌아가는 버튼도 필요한 거 같아."화면 피드백(5장)
"나는 남편의 기록을 와이프가 웹이나 어플에 들어가면 바로 볼 수 있는 형태를 원해"목표 설명(6장)
"플레이스토어에 올려 다른 사람들도 쓰게 할 계획이야. 공유 서버 방식으로 바꿔야 해."목표 변경(6장)
"니가 해줄 수 없나?"반복 작업 넘기기(6장)
"앱 아이콘 이미지 멋있는 디자인 없어?" → "B로 하고 싶어"시안 고르기(9장)
"안 되겠네 안 하는 게 낫겠네"기능 보류(5장)
