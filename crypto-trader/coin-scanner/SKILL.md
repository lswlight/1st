# coin-scanner

차트를 하나하나 넘겨 보는 일을 대신한다. 규칙에 맞는 차트 목록일 뿐 매수 목록이 아니다.

```bash
python3 "<이 폴더>/scan.py" daily                        # 일봉 셋업 (바이낸스 상위 30개)
python3 "<이 폴더>/scan.py" daily --symbols BTC,ETH,SOL
python3 "<이 폴더>/scan.py" orb                          # 09:20 KST 이후
python3 "<이 폴더>/scan.py" universe --check             # 거래대금 상위 30개로 목록 다시 만들기
python3 "<이 폴더>/scan.py" universe --check --exchange upbit   # 업비트 원화 목록
```

옵션: `--min-value`, `--show N`, `--json`, `--no-write`, `--now "2026-10-30 10:15"`, `--offline 폴더`.

## 데이터

- 기본: 바이낸스 현물 USDT (`data-api.binance.vision`). 가격 USDT, 거래대금 $.
- `-KRW` 심볼(`BTC-KRW`)은 업비트 원화 (`api.upbit.com`, 요청당 약 1초). `crt/config.json` 의
  `"crypto_source": "upbit"` 이면 `btc` 를 `BTC-KRW` 로 해석하고 업비트 목록을 쓴다.
- 하루는 09:00 KST(00:00 UTC)에 바뀐다. 진행 중인 오늘 일봉은 뺀다.
- 목록 다시 만들기: 스테이블코인, 레버리지 토큰, 토큰화 주식(GOOGLB 등: B를 뗀 티커가 Yahoo의 미국 주식이고 가격이 비슷하면) 제외. 업비트는 투자유의 종목 제외.

## 일봉 셋업 (볼린저 20일, 2σ)

| 셋업 | 규칙 |
| --- | --- |
| 볼린저 스퀴즈 후 상단 돌파 | 전날 밴드폭이 최근 120일 하위 20% 이내, 오늘 종가가 상단 위 |
| 볼린저 스퀴즈 진행 중 | 오늘 밴드폭이 최근 120일 하위 10% 이내 |
| 볼린저 하단 이탈 후 복귀 | 전날 종가가 하단 아래, 오늘 종가가 하단 위 |
| 20일 종가 신고가 | 오늘 종가가 직전 20일 종가보다 모두 높음 |
| 20일선 회복 | 전날 종가가 20일선 아래, 오늘 종가가 위 |
| 과매도 | RSI 14 (Wilder) 30 미만 |

## 09:00 범위 돌파

09:00·09:05·09:10 5분봉의 고가·저가가 범위다. 그 뒤 처음으로 5분봉 종가가 범위 고가 위에서
마감한 봉이 신호다. 빠진 봉이 있는 차트는 쓰지 않는다.

## 순서와 규칙

1. `daily` 또는 `orb`. 받은 수, 스캔 수, 셋업별 개수와 상위 코인을 말한다.
2. 사용자가 고르면 `/coin-news`, `/coin-signal`, `/coin-plan` 으로 넘긴다. 대신 골라 주지 않는다.
3. "규칙에 맞았다"고만 말한다. 수익률을 말하지 않는다. 신호는 가격이 움직이면 낡는다. 투자 조언이 아니다.
