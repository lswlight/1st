# 사진 위치 분류 (안드로이드 앱)

갤러리에 이미 있는 사진들의 촬영 위치(EXIF GPS)를 읽어 **나라 / 시·도 / 시·군·구** 단위로 묶어 보여주는 앱입니다.
사진 파일은 옮기거나 수정하지 않고, 앱 안에서 분류해서 보여주기만 합니다.

## 기능

- 갤러리 전체 사진 스캔 → GPS 좌표 추출 → 주소로 변환 → 지역별 그룹
- 분류 단위 전환: **생활권** / 나라 / 시·도 / 시·군·구 (예: `서울특별시 강남구`, `경기도 수원시`)
- **생활권 분류** (기본 화면): 🏠 집 / 🏢 회사 / 🏘️ 동네 / ✈️ 여행별 / 🚶 기타 외출
  - 집: 밤(21시~7시)에 사진을 찍은 날이 가장 많은 곳 (반경 300m)
  - 회사: 평일 낮(9시~18시)에 사진을 찍은 날이 가장 많은 곳 (반경 1km)
    또는 사진 화면의 **'○○시 전체를 회사로 설정'** 으로 시·군·구 전체를 회사로 지정 (예: 구미시)
  - 동네: 집에서 5km, 회사에서 2km 이내
  - 여행: 그 밖의 장소에서 36시간 넘게 끊기지 않고 이어 찍은 사진을 한 번의 여행으로 묶음
    (예: `✈️ 2025년 8월 강릉시 외 2곳 (3일)`). 3장 미만이면 '기타 외출'로 모음
  - 자동 감지가 틀리면 사진을 열어 **집으로 설정 / 회사로 설정** 으로 직접 지정
- 그룹 목록에 사진 수와 촬영 기간 표시 (예: `24장 · 2025.8.2 ~ 2026.10.3`)
- 그룹을 누르면 해당 지역 사진을 **날짜별로 나눠** 보여줌, 사진을 누르면 크게 보기 + 촬영일·좌표
- **자동 갱신**: 카메라로 사진을 찍고 앱으로 돌아오면 새 사진을 자동으로 확인해 분류 (새로고침 불필요)
- 지도 앱으로 위치 열기, 기본 갤러리 앱으로 사진 열기
- 위치가 없는 사진(스크린샷, 다운로드 이미지 등)은 `위치 정보 없음` 그룹으로 모음
- 한 번 읽은 사진·주소는 캐시해서 두 번째 실행부터는 새 사진만 처리

## 설치 방법 (APK)

1. 휴대폰 **크롬 브라우저**(GitHub 앱 말고)에서 아래 주소를 엽니다. 바로 apk 가 받아집니다.
   **https://github.com/lswlight/1st/releases/download/photo-app-latest/photo-location.apk**
2. 다운로드 알림이나 '내 파일 › 다운로드'에서 `photo-location.apk` 를 눌러 설치합니다.
   ("출처를 알 수 없는 앱 설치" 허용이 필요합니다.)
3. 처음 실행 시 **사진 접근 허용**을 누르고 "모두 허용"을 선택합니다.

앱 코드가 바뀌면 같은 주소에 새 버전이 자동으로 올라갑니다.

## 참고 사항

- 지원: Android 10 이상
- 주소 변환은 안드로이드 기본 Geocoder(구글 서비스)를 쓰므로 **처음 분류할 때 인터넷 연결이 필요**합니다.
  실패한 지역은 `주소 확인 실패` 그룹에 들어가며, 인터넷 연결 후 새로고침하면 다시 시도합니다.
- 좌표를 약 1km 격자로 묶어 격자당 한 번만 주소를 조회합니다. 격자 경계 근처 사진은 이웃 구로 분류될 수 있습니다.
- 카메라 앱에서 "위치 태그"를 꺼둔 상태로 찍은 사진은 위치가 없습니다.
  갤럭시: 카메라 → 설정(⚙️) → **위치 태그** 켜기, 휴대폰 위치(GPS)도 켜기.
- 카카오톡 등으로 받은 사진은 전송 과정에서 위치 정보가 지워지는 경우가 많습니다.

## 직접 빌드

Android Studio 로 `photo-location-app` 폴더를 열거나, Android SDK 가 설치된 환경에서:

```bash
cd photo-location-app
./gradlew assembleDebug
# 결과: app/build/outputs/apk/debug/app-debug.apk
```

## 코드 구조

| 파일 | 역할 |
|---|---|
| `PhotoRepository.kt` | MediaStore 사진 목록 조회, EXIF GPS 읽기, 캐시 |
| `LocationNamer.kt` | 좌표 → 주소(나라/시·도/시·군·구) 변환, 격자 캐시 |
| `GalleryViewModel.kt` | 스캔 진행 상태, 지역별 그룹 만들기 |
| `MainActivity.kt` | 권한 요청, 그룹 목록 / 사진 그리드 / 사진 보기 화면 (Jetpack Compose) |
