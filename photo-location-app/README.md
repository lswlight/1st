# 앨범 박스 (안드로이드 앱)

갤러리에 이미 있는 사진·동영상을 촬영 위치(GPS)와 출처로 묶어 보여주는 앱입니다.
(사진은 EXIF, 동영상은 메타데이터의 위치를 읽습니다. 화면 녹화는 스크린샷 그룹으로 모읍니다.)
앱 안에서 분류해 보여주기만 하며, 원본 파일은 'PC로 내보내기'에서 이동을 고를 때만 옮깁니다.

## 분류 구조

```
🏠 집                     ← GPS 가 집 반경 300m
🏢 회사                   ← GPS 가 회사 반경 1km (또는 지정한 시 전체)
대구                      ← 그 밖은 지역 이름 (광역시는 도시 이름만)
경상북도                  ← 도는 아래에 시·군 폴더 (포항시, 김천시 …)
일본                      ← 해외는 나라 아래 주/도 폴더 (도쿄도 …)
위치 정보 없음             ← 카메라로 찍었지만 GPS 없음
💬 카카오톡 / 📱 스크린샷 / ⬇️ 다운로드 / 🗂️ 기타 앱   ← 받은 사진은 위치와 상관없이 출처별
```

모든 그룹은 **그룹 › 월 폴더(📁 2026년 10월) › 사진** 순서로 들어갑니다.
도·해외는 한 단계 더: **경상북도 › 포항시 › 📁 2026년 10월 › 사진**

## 기능

- 갤러리 전체 사진 스캔 → GPS 좌표 추출 → 주소로 변환 → 위 구조로 분류
- **집·회사**: 자동 감지 (집: 밤 21시~7시에 찍은 날이 가장 많은 곳 / 회사: 평일 9시~18시)
  - 목록 위 **📍 집·회사 설정**(평소엔 접혀 있음)에서 **주소로 집 지정 / 주소로 회사 지정**
  - 사진 화면의 **집으로 설정 / 회사로 설정 / ○○시 전체를 회사로 설정**
- **받은 사진**: 저장 폴더를 보고 카카오톡·스크린샷·다운로드·기타 앱(폴더 이름)으로 구분.
  위치 정보가 남아 있어도 지역 분류에는 섞지 않음
- 그룹 목록에 사진 수와 촬영 기간 표시, 월 폴더 안은 날짜별로 구분, 사진을 누르면 크게 보기 + 촬영일·좌표
- **자동 갱신**: 카메라로 사진을 찍고 앱으로 돌아오면 새 사진을 자동으로 확인해 분류
- 지도 앱으로 위치 열기, 기본 갤러리 앱으로 사진 열기
- **PC로 내보내기** (상단 공유 아이콘): 선택한 그룹을 `Pictures/앨범박스/그룹/2026년 10월/` (도는 `경상북도/포항시/2026년 10월/`) 폴더로 정리
  - 복사: 원본 유지, 복사본 생성 / 이동: 원본을 그룹 폴더로 옮김 (Android 11+, 시스템 허락 필요)
  - USB 로 PC 에 연결해 `내 PC › 휴대폰 › 내장 메모리 › Pictures › 앨범박스` 를 복사
  - 옮긴 뒤 **분류 폴더 비우기**로 폰에서 정리 (휴지통으로 이동, 30일 안에 복구 가능)
- 한 번 읽은 사진·주소는 캐시해서 두 번째 실행부터는 새 사진만 처리

## 설치 방법 (APK)

1. 휴대폰 **크롬 브라우저**(GitHub 앱 말고)에서 아래 주소를 엽니다. 바로 apk 가 받아집니다.
   **https://github.com/lswlight/1st/releases/download/photo-app-latest/photo-location.apk**
2. 다운로드 알림이나 '내 파일 › 다운로드'에서 `photo-location.apk` 를 눌러 설치합니다.
   ("출처를 알 수 없는 앱 설치" 허용이 필요합니다.)
3. 처음 실행 시 **사진 접근 허용**을 누르고 "모두 허용"을 선택합니다.

앱 코드가 바뀌면 같은 주소에 새 버전이 자동으로 올라갑니다.

## 참고 사항

- 지원: Android 10 이상
- 주소 변환은 안드로이드 기본 Geocoder(구글 서비스)를 쓰므로 **처음 분류할 때 인터넷 연결이 필요**합니다.
  실패한 지역은 `주소 확인 실패` 그룹에 들어가며, 인터넷 연결 후 새로고침하면 다시 시도합니다.
- 좌표를 약 1km 격자로 묶어 격자당 한 번만 주소를 조회합니다. 격자 경계 근처 사진은 이웃 지역으로 분류될 수 있습니다.
- 카메라 앱에서 "위치 태그"를 꺼둔 상태로 찍은 사진은 위치가 없습니다.
  갤럭시: 카메라 → 설정(⚙️) → **위치 태그** 켜기, 휴대폰 위치(GPS)도 켜기.
- 카카오톡 등으로 받은 사진은 전송 과정에서 위치 정보가 지워지는 경우가 많습니다.

## 직접 빌드

Android Studio 로 `photo-location-app` 폴더를 열거나, Android SDK 가 설치된 환경에서:

```bash
cd photo-location-app
./gradlew assembleDebug
# 결과: app/build/outputs/apk/debug/app-debug.apk
```

## 아이콘

`tools/icon_source.png` 를 `python3 tools/make_icon.py` 로 적응형 아이콘(전경·배경)으로 변환합니다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `PhotoRepository.kt` | MediaStore 사진 목록 조회, EXIF GPS 읽기, 캐시 |
| `LocationNamer.kt` | 좌표 → 주소 변환, 지역 그룹 이름 규칙, 격자 캐시 |
| `LifeClassifier.kt` | 집·회사 자동 감지와 판별 |
| `PhotoSource.kt` | 저장 폴더로 받은 사진 출처 구분 |
| `Exporter.kt` | PC 로 내보내기 (그룹/월 폴더로 복사·이동, 휴지통) |
| `GalleryViewModel.kt` | 스캔 진행 상태, 그룹 만들기, 내보내기 진행 |
| `AlbumBoxApp.kt` | 동영상 썸네일용 이미지 로더 설정 |
| `MainActivity.kt` | 권한 요청, 그룹 목록 / 월 폴더 / 사진 그리드 / 사진 보기 / 내보내기 화면 (Jetpack Compose) |
