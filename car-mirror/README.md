# CarMirror (개인용)

휴대폰 화면을 안드로이드 오토 차량 화면에 띄우는 개인용 앱입니다. 유튜브, 넷플릭스 같은 앱을 휴대폰에서 실행하면 차량 화면에 그대로 보입니다.

- **정차 중에만 화면 표시.** 차량 속도(안드로이드 오토 제공)나 GPS 속도로 정차를 확인하고, 주행 중에는 화면을 가립니다. 소리는 계속 나옵니다.
- **차량 화면 터치.** 정차 중에는 차량 화면을 누르면 휴대폰에서 같은 위치가 눌립니다. 뒤로, 홈, 최근 앱 버튼도 있습니다.
- 플레이스토어 배포용이 아닌 개인 사이드로드 전용입니다. Fermata 코드는 쓰지 않았습니다.

## 동작 구조

```
휴대폰 화면 ──(MediaProjection 화면 캡처)──▶ ImageReader ──▶ 차량 화면 Surface
                                                        ▲
                         ParkingGuard (차량 속도 / GPS) ─┘  주행 중이면 영상 대신 안내 문구
```

| 파일 | 역할 |
|---|---|
| `CarMirrorService` | 안드로이드 오토 진입점. 공식 Car App Library의 NAVIGATION 카테고리를 써서 자유 화면(Surface)을 받습니다. |
| `MirrorScreen` | 차량 화면 템플릿, 차량 속도 수신, 터치 전달 |
| `MirrorController` | 휴대폰 화면 프레임을 차량 화면에 그리고, 잠금 상태면 안내 문구를 그림 |
| `ParkingGuard` | 정차 판정 (아래 기준) |
| `ProjectionService` | 화면 캡처 유지용 포그라운드 서비스, GPS 시작 |
| `TouchService` | 접근성 서비스. 차량 화면 터치를 휴대폰 제스처로 전달 |
| `MainActivity` | 휴대폰 화면. 권한, 시작/중지, 상태 표시 |

### 정차 판정 기준

| 조건 | 판정 |
|---|---|
| 차량 속도가 있으면 그 값만 사용. 0.3 m/s(약 1 km/h) 이상 | 주행 → 화면 가림 |
| 차량 속도가 없으면 GPS. 1.5 m/s(약 5 km/h) 이상 | 주행 → 화면 가림 |
| 정지 속도가 3초 이상 이어짐 | 정차 → 화면 표시 |
| 속도 정보가 30초 넘게 없음, 또는 앱 시작 직후 | 확인 불가 → 화면 가림 |

지하주차장처럼 GPS가 안 잡히고 차량 속도도 안 오는 곳에서는 화면이 가려진 채로 있습니다. 안전을 우선한 동작입니다.

## APK 받기

`car-mirror/` 를 수정해 push 하면 GitHub Actions가 자동으로 빌드합니다.

1. GitHub 저장소 → **Actions** → **CarMirror APK** → 최근 성공한 실행 선택
2. 아래 **Artifacts** 의 `CarMirror-apk` 다운로드 → 압축을 풀면 `CarMirror.apk`

로컬 빌드: Android SDK가 있는 PC에서 `cd car-mirror && gradle assembleRelease`

휴대폰에서 바로 받기: 저장소 **Releases** → `CarMirror (최신 빌드)` → `CarMirror.apk`

## 설치 방법 A: 휴대폰만으로 (PC 없음)

**1단계: 그냥 설치해 보기**
1. 휴대폰에서 `CarMirror.apk` 를 받아 눌러 설치 (출처를 알 수 없는 앱 허용)
2. 안드로이드 오토 설정 → **버전** 10번 탭 → `⋮ → 개발자 설정` → **알 수 없는 출처** 체크
3. 차량에 연결해 앱 목록에 CarMirror 가 보이면 끝

**2단계: 안 보이면 Shizuku + InstallWithOptions 로 다시 설치** (안드로이드 11 이상, Wi-Fi 연결 필요)
1. 플레이스토어에서 **Shizuku** 설치
2. 개발자 옵션 켜기: `설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호` 7번 탭
3. Shizuku 실행 → **무선 디버깅으로 시작** → 안내대로 `개발자 옵션 → 무선 디버깅 → 페어링 코드로 기기 페어링` 의 코드를 Shizuku 알림에 입력 → 시작
4. GitHub `zacharee/InstallWithOptions` 의 Releases 에서 APK 를 받아 설치 → 실행 → Shizuku 권한 허용
5. 기존 CarMirror 삭제
6. InstallWithOptions 에서 **설치 프로그램 패키지(Installer package)** 를 `com.android.vending` 으로 지정 → `CarMirror.apk` 선택 → 설치
7. 차량에 다시 연결해 확인

Shizuku 는 휴대폰을 재부팅하면 3번을 다시 해야 하지만, CarMirror 는 한 번 설치하면 그대로 남습니다.

## 설치 방법 B: PC + adb

안드로이드 오토는 플레이스토어에서 설치되지 않은 앱을 숨기기 때문에, 설치 출처를 지정해 adb로 설치합니다.

1. PC에 [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools) 설치
2. 휴대폰: `설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호` 7번 탭 → 개발자 옵션 → **USB 디버깅** 켜기
3. 휴대폰을 USB로 연결하고 실행:
   ```
   adb devices
   adb install -r -i com.android.vending CarMirror.apk
   ```
4. 안드로이드 오토 설정 → 맨 아래 **버전** 10번 탭 → `⋮ → 개발자 설정` → **알 수 없는 출처** 체크
5. 안드로이드 오토 설정 → **런처 맞춤설정** 에서 CarMirror 가 체크되어 있는지 확인

## 사용법

1. 차량에 연결하고 안드로이드 오토 앱 목록에서 **CarMirror** 실행
2. 휴대폰에서 CarMirror 앱 → **미러링 시작** → 위치·알림 권한 허용 → 화면 공유에서 **전체 화면** 선택
3. 유튜브 등을 열고 휴대폰을 가로로 돌리면 차량 화면을 꽉 채웁니다
4. 터치 제어: **터치 제어 켜기** → 설치된 앱 → `CarMirror 터치 제어` 켜기
   - 회색으로 막혀 있으면 (안드로이드 13 이상 제한된 설정): **앱 정보 열기** → 오른쪽 위 `⋮` → **제한된 설정 허용** 후 다시 시도
5. 스크롤: 차량 화면의 이동(PAN) 버튼을 누른 뒤 드래그

## 독립 화면 모드 (실험)

휴대폰 화면 복사 대신, 차량 화면 크기의 별도 가상 화면을 만들고 거기에 앱을 띄웁니다. 휴대폰은 따로 쓸 수 있습니다. 정차 중에만 표시되는 기준은 같습니다.

1. 휴대폰 CarMirror 앱 → **독립 화면 시작 (실험)** → 화면 공유 허용
2. 안드로이드 오토에서 CarMirror 열기 (차량 화면에 '독립 화면 준비됨' 표시)
3. **1) 테스트 화면 띄우기** → 차량에 파란 화면과 시계가 보이면 가상 화면 자체는 동작
4. **2) 앱 골라서 띄우기** → 유튜브 등 선택

안드로이드는 일반 앱이 만든 가상 화면에 다른 앱을 띄우는 것을 막을 수 있습니다. 앱이 차량이 아니라 휴대폰에 열리거나 오류가 나오면 그 기기에서는 막힌 것이고, 휴대폰 앱 화면의 결과 메시지로 확인할 수 있습니다.

## 알려진 제약

- **앱 목록 인식은 보장되지 않습니다.** 위 설치 방법이 휴대폰·안드로이드 오토 버전에 따라 막힐 수 있습니다.
- 휴대폰 화면이 꺼지거나 잠기면 화면 캡처가 멈춥니다. 충전 중 화면 켜짐 유지(개발자 옵션 → 화면 켜짐 상태 유지)를 권장합니다.
- 넷플릭스 등 DRM 앱은 화면 캡처를 막아 **검은 화면**으로 나올 수 있습니다. 유튜브는 보통 정상입니다.
- 안드로이드 오토 버전에 따라 차량 화면 탭(`onClick`)이나 차량 속도가 전달되지 않을 수 있습니다. 이 경우 GPS로만 판정하고 터치는 휴대폰에서 직접 합니다.
- 서명 키(`keystore/personal.jks`)는 개인 사이드로드용 고정 키입니다. 같은 키로 빌드한 APK끼리는 삭제 없이 덮어쓰기 설치가 됩니다.

## 법규

도로교통법 제49조에 따라 운전자가 볼 수 있는 화면에 주행 중 영상을 표시하는 것은 금지됩니다. 이 앱은 정차 중 사용을 전제로 하며, 주행 중 화면 차단을 해제하는 기능은 넣지 않았습니다.
