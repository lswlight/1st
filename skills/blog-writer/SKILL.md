# 블로그 글 작성 (SEO + 해요체)

목표는 **검색에 걸리면서도 사람이 끝까지 읽는 글**이다.
모든 결과는 한국어로 작성한다. 단계는 반드시 순서대로 진행하고, **2단계 뒤에는 멈춰서 사용자의 제목 선택을 기다린다.**

## 0. 입력 확인

- 필수: 글 주제(한 줄이면 충분). 없으면 주제를 묻는다.
- 선택(없으면 묻지 말고 기본값으로 진행):
  - 타깃 독자 → 기본값: 주제에 관심 있는 입문자
  - 블로그 플랫폼 → 기본값: 네이버 블로그·티스토리 공통 형식(마크다운)
  - 내 블로그 글 목록 또는 URL → 6단계 내부 링크에 사용
  - 참고 자료(메모, 기사, 유튜브 분석 결과) → 본문의 근거로 사용
- 사용자가 처음부터 제목을 정해 주면 1~2단계는 키워드 추출만 하고 3단계로 바로 간다.

## 1. SEO 타겟 키워드 3개 추출

| 구분 | 역할 | 예시 (주제: 볼린저 밴드 매매법) |
|---|---|---|
| 메인 키워드 | 제목·첫 문단·H2·alt에 들어갈 핵심어 | 볼린저 밴드 |
| 서브 키워드 1 | 검색 의도를 좁히는 롱테일 | 볼린저 밴드 매매법 |
| 서브 키워드 2 | 연관 질문·문제형 | 볼린저 밴드 수축 |

- 사람들이 실제로 검색창에 칠 말로 고른다. 전문 용어만 있으면 일상어 버전을 서브 키워드로 둔다.
- 각 키워드 옆에 **검색 의도**(정보형/비교형/방법형/구매형)를 한 단어로 적는다.
- 검색량 수치는 지어내지 않는다. 확인할 수 없으면 "검색량 미확인"이라고 쓴다.

## 2. 제목 후보 5개 (숫자 + 키워드)

- 5개 모두 **숫자**와 **메인 키워드**를 포함한다. 메인 키워드는 가능하면 제목 앞쪽에 둔다.
- 유형을 섞는다: 리스트형(5가지), 방법형(3단계), 실수형(7가지 실수), 기간형(30일), 비교형(2가지 차이).
- 길이는 공백 포함 25~40자 안팎.
- 과장 금지: "무조건", "100% 수익", "충격", "역대급" 같은 표현을 쓰지 않는다.
- 표로 번호·제목·유형·한 줄 이유를 보여 준다.

> 여기서 멈춘다. "몇 번 제목으로 갈까요? 수정하고 싶은 부분이 있으면 말씀해 주세요." 라고 묻고 답을 기다린다.

## 3. 아웃라인 (사용자가 제목을 고른 뒤)

- H1: 선택한 제목
- 도입부 hook 방향 한 줄
- **H2 4~6개.** 각 H2에 메인 또는 서브 키워드를 자연스럽게 넣는다. 모든 H2에 같은 키워드를 반복하지 않는다.
- 각 H2 아래에 핵심 한 줄 요약 + 다룰 내용 2~3개(필요하면 H3)
- 비유를 넣을 위치 2곳 이상 표시
- 이미지 위치와 alt 텍스트 초안
- 마무리 CTA 방향

아웃라인을 보여 주고 바로 4단계로 이어 간다. 사용자가 아웃라인만 원하면 거기서 멈춘다.

## 4. 본문 작성 (1,500~2,500자, 공백 제외)

[references/post-template.md](references/post-template.md) 양식을 따른다.

### 스타일 규칙
- **해요체**로 대화하듯 친근하게 쓴다. "~입니다/~합니다/~습니다" 체는 쓰지 않는다. (인용문, 고유명사 안의 표현은 예외)
- **도입부 3줄 이내에 hook**: 독자의 고민, 의외의 사실, 질문 중 하나로 시작한다.
- **첫 문단에 메인 키워드**를 넣는다.
- **소제목(H2)마다 첫 줄은 핵심 한 줄 요약**으로 시작한다. 형식: `> 핵심: ...`
- **비유를 최소 2개** 넣는다. 독자가 아는 일상 경험(요리, 운전, 날씨, 운동 등)에 빗댄다.
- 문단은 2~4문장으로 짧게 끊는다. 목록과 표를 적절히 섞는다.
- 이미지는 `![alt 텍스트](이미지 설명)` 형태로 2~3개 자리만 잡는다. **alt 텍스트에 키워드를 포함**하되 문장으로 자연스럽게 쓴다.
- **마무리 CTA**: 댓글 유도 질문 + 구독(이웃 추가) 권유 + 다음 글 링크 한 줄.

### SEO 규칙
- 타겟 키워드를 **제목, 첫 문단, 소제목**에 포함한다.
- **H2 4~6개**.
- 메인 키워드 밀도 **1~2%** (계산 방법은 아래 검사 스크립트 기준). 2%를 넘으면 대명사나 유의어로 바꾼다.
- 같은 문장에 키워드를 두 번 넣지 않는다.

### 금지
- 과장 표현, 근거 없는 주장. 수치·통계·효과를 말할 때는 출처를 밝히거나 "제 경험으로는", "일반적으로" 처럼 범위를 한정한다. 모르는 수치는 만들지 않는다.
- 투자·건강·법률 주제는 수익이나 효과를 보장하는 표현을 쓰지 않고, 마지막에 "참고용이며 판단은 본인 몫"이라는 한 줄을 넣는다.
- 키워드 과다 삽입. 읽었을 때 어색하면 밀도가 1% 이상이어도 줄인다.

## 5. 메타 설명 (155자 이내, 공백 포함)

- 메인 키워드를 앞쪽에 넣는다.
- 독자가 얻는 것 + 행동 유도로 구성한다. 해요체.
- 글자 수를 함께 적는다.

## 6. 내부 링크 추천 3개

- 사용자가 글 목록·URL을 줬다면 그중에서 관련도 높은 3개를 고르고, 본문 어디에 어떤 앵커 텍스트로 넣을지 제안한다.
- 목록이 없으면 **URL을 지어내지 않는다.** 대신 "이어서 쓰면 좋은 글" 3개를 제목·앵커 텍스트·삽입 위치로 제안하고 `[링크 추가]`로 표시한다.

## 7. 자가 검사 (출력 전)

코드 실행이 가능하면 본문을 파일로 저장한 뒤 검사 스크립트를 돌린다.

```bash
python3 scripts/check_post.py post.md --keyword "메인 키워드" --sub "서브1" --sub "서브2" --meta "메타 설명 문장"
```

스크립트가 없거나 실행이 안 되면 같은 항목을 직접 세어 확인한다. 실패 항목이 있으면 고친 뒤 다시 검사하고, 최종 출력 끝에 체크리스트 결과를 짧게 붙인다.

| 항목 | 기준 |
|---|---|
| 본문 길이 | 공백 제외 1,500~2,500자 |
| H2 개수 | 4~6개 |
| 키워드 위치 | 제목, 첫 문단, H2 1개 이상 |
| 키워드 밀도 | 1~2% |
| 핵심 요약 | 모든 H2 첫 줄 |
| 이미지 alt | 키워드 포함 |
| 문체 | "~입니다/합니다/습니다" 0회 |
| 메타 설명 | 155자 이내 |

## 출력 형식

1~2단계 응답:
```
## 1. 타겟 키워드
(표)
## 2. 제목 후보
(표)
몇 번 제목으로 갈까요?
```

3~7단계 응답:
```
## 3. 아웃라인
## 4. 본문        ← 그대로 복사해 붙여 넣을 수 있게 마크다운으로
## 5. 메타 설명 (N자)
## 6. 내부 링크 추천
## 검사 결과
```
