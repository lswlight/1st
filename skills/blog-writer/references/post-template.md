# 본문 양식

아래 뼈대를 채운다. `{ }` 부분만 바꾸고, H2 개수는 4~6개 사이에서 주제에 맞게 조정한다.

```markdown
# {선택한 제목}

{hook 1~3줄: 독자의 고민 / 의외의 사실 / 질문. 첫 문단에 메인 키워드 포함}

{이 글에서 얻을 것 한두 줄}

![{메인 키워드가 들어간 이미지 설명 문장}]({대표 이미지 설명})

## {H2-1: 키워드 포함}

> 핵심: {이 섹션을 한 줄로}

{본문 2~4문장 문단 2~3개}

## {H2-2}

> 핵심: {한 줄 요약}

{본문. 비유 1: "~는 마치 ~와 비슷해요."}

## {H2-3: 서브 키워드 포함}

> 핵심: {한 줄 요약}

{본문. 목록 또는 표}

![{서브 키워드가 들어간 이미지 설명 문장}]({이미지 설명})

## {H2-4}

> 핵심: {한 줄 요약}

{본문. 비유 2}

## {H2-5: 정리 / 자주 묻는 질문 등 (선택)}

> 핵심: {한 줄 요약}

{본문}

---

{마무리 2~3줄: 핵심 다시 짚기}

💬 {댓글 유도 질문}
🔔 {구독·이웃 추가 권유 한 줄}
👉 다음 글: [{다음 글 제목}]({링크 또는 [링크 추가]})
```

## 해요체 바꾸기 예시

| 피할 표현 | 바꾼 표현 |
|---|---|
| 중요합니다 | 중요해요 |
| 확인할 수 있습니다 | 확인할 수 있어요 |
| ~하는 것이 좋습니다 | ~하는 게 좋아요 |
| 알아보겠습니다 | 알아볼게요 |
| 결론적으로 말씀드리면 | 정리하면 |

## 과장 표현 바꾸기 예시

| 피할 표현 | 바꾼 표현 |
|---|---|
| 무조건 수익 나는 방법 | 제가 써 보고 효과를 본 방법 |
| 100% 성공 | 성공 확률을 높이는 |
| 모두가 모르는 비밀 | 생각보다 잘 안 알려진 |
| 역대급 / 충격 | (삭제하고 구체적인 사실로 대체) |
